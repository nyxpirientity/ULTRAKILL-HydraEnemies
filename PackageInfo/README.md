# Important!
For this plugin/mod to work, you'll need to ensure your BepInEx is configured to have *`HideManagerGameObject`* set to *`true`*, or else the game will destroy the plugin!

# about
Hydra is my first mod which I'm only just now making available here. It adds a cheat to the game in which the concept is simple, when an enemy dies, it splits into another two with half the health. You have a short time period where if you kill either of those two enemies or both of them, they won't spawn another two. If you miss that window, then when you kill them, those two will spawn another two each with half of *their* health, same applies to their clones, and the clone's clone's, and so on.
